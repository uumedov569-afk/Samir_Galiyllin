## Описание
Приложение "Random Quote Generator" — это графическое приложение на Python с использованием библиотеки Tkinter, которое генерирует случайные цитаты из предопределённого списка или добавленных пользователем цитат.

### Основные возможности:
- Генерация случайной цитаты по нажатию кнопки
- Отображение истории сгенерированных цитат
- Фильтрация истории по автору и теме
- Добавление новых цитат с проверкой на пустые строки
- Автоматическое сохранение цитат и истории в JSON-файлы
- Загрузка данных при запуске приложения

## Требования
- Python 3.6 или выше
- Стандартные библиотеки: tkinter, json, random, os, datetime
